# The World Today — Saturday 21 November 2026

One image that sums up the world's news of **Saturday 21 November 2026**:
a procedural newspaper front page drawn entirely by code — no photographs,
no copied artwork.

## What the page shows

- **Lead:** COP31 in Antalya runs into overtime — the draft deal does not
  even name fossil fuels, and activists call it the worst COP ever.
- **World map** with the day's flashpoints marked: Antalya, Riyadh, Peru,
  Kyiv, The Hague.
- **Six illustrated panels:** COP31 overtime · Riyadh intercepts 3 Houthi
  missiles · Peru M6.7 quake felt in Lima · BepiColombo enters Mercury orbit
  after 8 years · Kyiv's bridges hit in the war's biggest air attack of the
  year · the ICJ's genocide ruling against Myanmar.
- **A UTC timeline** of the day, from the 00:09 Peru quake to the COP31
  extension.
- **40 numbered stories** across every region and beat — war and diplomacy,
  climate, markets (S&P 500 and Dow into correction, Nvidia −14%), science,
  health, justice and sport of the day — each one reported on 21 November 2026.

## How it is built

`main.ts` (Node 22, standard library only, no network) draws the whole
1024×1024 front page pixel by pixel — masthead, map, panels, timeline and
all 40 stories — with its own tiny 5×7 bitmap font and its own PNG encoder,
then writes it to the output directory. Nothing is read from disk at run
time; the same source always writes the same bytes.

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

Run it twice and the two `entry.png` files are byte-identical.
